# SR Apps

Colección de aplicaciones web móviles (**PWA**) listas para usar directamente desde tu celular vía GitHub Pages (HTTPS automático, sin servidor propio).

## Apps incluidas

### STARK BEAM — Escáner Óptico y Transmisión a Pantallas
- **App Todo-en-Uno:** `https://santosrositas.github.io/sr-apps/stark-beam/`

Incluye **2 modos en la misma página**:
1. **`◎ ESCÁNER` (Celular):**
   - Detección óptica en tiempo real de monitores y TVs mediante análisis de componentes conectados, rectangularidad y contraste de bisel (toca cualquier monitor en cámara para fijar prioridad).
   - Lectura automática de código QR de largo alcance (con recorte ROI sobre la pantalla detectada) + enlace manual por código de 4 letras.
   - Transmisión directa **WebRTC P2P** de **JPEG, PNG, MP3, MP4 y MOV** con gesto *Flick-Up* y controles remotos (Play/Pausa, Seek, Volumen, Mute, Liberar).
2. **`▣ RECEPTOR TV` (Monitor / TV / PC):**
   - Muestra un código QR de alto contraste (versión compacta legible a distancia) + código de 4 letras.
   - Recibe archivos con barra de progreso, dispara el efecto **Signal Override** estilo *Iron Man 2* y reproduce imagen, video o audio (con visualizador Arc Reactor) a pantalla completa.
