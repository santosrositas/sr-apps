# SR Apps

Colección de aplicaciones web móviles (**PWA**) listas para usar directamente desde tu celular vía GitHub Pages (HTTPS automático, sin servidor propio).

## Apps incluidas

### STARK BEAM (Iron Man 2 Screen Override)
- **App Móvil (Celular):** `https://santosrositas.github.io/sr-apps/stark-beam/`
- **Pantalla Receptora (TV / Monitor):** `https://santosrositas.github.io/sr-apps/stark-beam/receiver.html`

#### Modos de uso
1. **AR HIJACK (100% solo desde tu celular):** Apunta la cámara trasera a cualquier monitor o TV físico, selecciona un archivo **JPEG, PNG, MP3, MP4 o MOV** y desliza hacia arriba (*Flick*) para proyectarlo encima en **perspectiva 3D real (`matrix3d`)** con ajuste manual de las 4 esquinas.
2. **TV P2P (Transmisión real sin servidor):** Abre `receiver.html` en una TV o monitor con navegador, cambia a **TV P2P** en tu celular, apunta la cámara al **código QR** en la pantalla (se enlaza automáticamente por WebRTC P2P) y desliza hacia arriba para reproducir tu archivo a pantalla completa con controles remotos en vivo.

#### Instalar como App en tu celular
- **iPhone (Safari):** Abre STARK BEAM → botón **Compartir** → **Agregar a pantalla de inicio**.
- **Android (Chrome):** Abre STARK BEAM → menú **⋮** → **Instalar aplicación / Agregar a pantalla principal**.
